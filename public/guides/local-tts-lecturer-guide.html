Cài Local TTS từng bước một

Ứng dụng Windows dùng GPU NVIDIA trên máy giảng viên để tạo audio. Bạn chỉ cần cài ứng dụng, chọn bộ model do trường cấp và kết nối máy với LearnAble.

1

Chuẩn bị

Đảm bảo máy và thông tin bàn giao đã sẵn sàng.

Máy cần Windows 10/11 64-bit, GPU NVIDIA hoạt động và Internet. Bạn có thể xem tên GPU trong Task Manager → Performance → GPU. Hỏi nhóm triển khai về dung lượng trống cần thiết cho gói model thực tế.

Chưa có link tải công khai đã xác nhậnBộ cài và model phải do nhóm triển khai bàn giao. Chỉ có file adapter từ Kaggle thì chưa đủ. Bạn không cần tự cài Python, CUDA Toolkit hoặc chạy Backend.

Nếu tải model qua ứng dụng, cần thêm URL HTTPS của manifest.json và mã SHA-256 do nhóm xác nhận.

Tải README để xem khi không mở trang này.

2

Cài ứng dụng và model

Làm một lần trên máy dùng để tạo audio.

  1. Chạy bộ cài

    Mở LearnAble-TTS-Setup.exe, làm theo màn hình cài đặt, rồi mở LearnAble TTS Agent từ Start Menu. Tìm biểu tượng trong khay hệ thống ở góc phải taskbar; mở danh sách biểu tượng ẩn nếu cần.

  2. Nhập địa chỉ LearnAble

    Nhấp chuột phải vào biểu tượng, chọn Settings. Điền API URL (include /api/v1) và Web dashboard URL từ nhóm triển khai. Hai địa chỉ phải dùng HTTPS và cùng môi trường. Đặt Device label; để trống Runtime executable (optional) với bộ cài đầy đủ.

  3. Chọn gói model

    Nếu nhận file nén, giải nén và chọn thư mục chứa trực tiếp manifest.json và manifest.sha256 tại Verified model folder. Giữ nguyên vị trí thư mục. Nếu được cấp URL tải, chọn Check for Updates / Install Package → Model, dán URL manifest HTTPS và mã SHA-256, rồi chờ xác minh xong.

  4. Kiểm tra GPU

    Chọn Check GPU. Hộp thoại cần thấy GPU NVIDIA, VRAM, PyTorch và CUDA. Kiểm tra này chưa thay thế bước tạo audio thử.

3

Kết nối thiết bị

Dùng thông tin một lần từ trang Lecturer.

  1. Mở Pair Device

    Trên ứng dụng Windows, chọn Pair Device và để cửa sổ này mở.

  2. Đăng ký máy trên web

    Đăng nhập trang Lecturer cùng môi trường với API trong Settings. Vào Learning Materials → Upload new material → Đăng ký máy tạo audio. Nhập tên máy rồi chọn Đăng ký máy.

  3. Dán thông tin vào ứng dụng

    Chép Agent ID và Expires at (ISO 8601). Chọn Sao chép token một lần rồi dán vào Device token. Nhấn OK và chờ báo kết nối thành công. Thông tin trên web tự ẩn sau hai phút.

Giữ kín tokenKhông gửi token hay ảnh chụp token cho người khác. Token hết hạn sau khoảng tám giờ; khi hết hạn, đăng ký máy mới và Pair Device lại. Khi đổi tài khoản, chọn Unpair Device trước.

Nếu trang Lecturer chưa có mục đăng ký, nhóm triển khai có thể cấp trang BE /local-tts/ của cùng môi trường.

4

Tạo audio thử

Thử một trang ngắn trước khi làm cả tài liệu.

  1. Giữ ứng dụng đang chạy

    Cắm nguồn laptop, giữ Internet và tránh chế độ Sleep.

  2. Chọn trang PDF có chữ

    Mở Material Audio Studio, kiểm tra phần text sẽ đọc, chọn một trang ngắn và yêu cầu tạo audio.

  3. Nghe và duyệt

    Chờ web báo audio đã sẵn sàng, chọn Preview để nghe. Chỉ Approve khi giọng đọc đúng. Sau đó mới tạo audio cho cả tài liệu.

Ứng dụng có thể hiện IDLE, GENERATING hoặc UPLOADINGIDLE là đang chờ việc; GENERATING là đang tổng hợp; UPLOADING là đang gửi audio về hệ thống.
5

Dùng lại và xử lý lỗi

Không phải cài lại mỗi lần tạo audio.

Những lần sau, mở ứng dụng từ Start Menu hoặc để ứng dụng tự chạy cùng Windows. Nếu thấy PAIRING_REQUIRED, đăng ký lại thiết bị trên web. Pause / Resume chỉ tạm dừng nhận job mới; job đang chạy vẫn tiếp tục.

Check GPU không thấy NVIDIA

Kiểm tra GPU trong Task Manager và driver NVIDIA. Khởi động lại Windows sau khi cập nhật driver. Gửi tên GPU và lỗi cho nhóm kỹ thuật.

MODEL_SETUP_REQUIRED hoặc model lỗi

Kiểm tra thư mục model có hai file manifest hoặc xin lại URL manifest và mã SHA-256. Không bỏ qua xác minh model.

Ứng dụng báo IDLE nhưng web đang chờ audio

Kiểm tra web và ứng dụng dùng cùng API/môi trường, cùng tài khoản Lecturer và model tương thích. Gửi thời điểm và mã lỗi cho nhóm kỹ thuật.

Audio chờ lâu hoặc thất bại

Chọn View Logs trong menu ứng dụng. Gửi mã lỗi, thời điểm, tên GPU; không gửi token, mật khẩu hoặc URL upload có chữ ký.

Trước khi gỡ cài đặt hoặc đổi tài khoản, chọn Unpair Device. Nếu máy mất mạng, thu hồi thiết bị trên web khi có mạng trở lại.
