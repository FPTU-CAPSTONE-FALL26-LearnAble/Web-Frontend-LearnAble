1

Trước khi bắt đầu

Kiểm tra những thứ cần có. Chưa đủ thì dừng ở đây, bạn vẫn có thể upload tài liệu trên web.

Local TTS là chương trình chạy trên máy của bạn để tạo giọng đọc. Các bước bên dưới dùng PowerShell, ứng dụng có sẵn trên Windows. Bạn cũng có thể tải README ngắn gọn để làm theo khi không mở trang này.

  • Máy tính: nên dùng Windows 11 64-bit, có GPU NVIDIA hỗ trợ CUDA. Cần Internet ổn định, ổ SSD còn khoảng 20 GB và nên có 16 GB RAM. Dung lượng GPU 6–8 GB là mức chuẩn bị đề xuất, không phải cam kết mọi máy sẽ chạy được.
  • Tài khoản: tài khoản Lecturer đang hoạt động, đã đổi mật khẩu lần đầu nếu hệ thống yêu cầu.
  • Hai thư mục trên máy: C:\LearnAble\Backend-LearnAble có thư mục con tts-agent; C:\LearnAble\VieNue-LoRA có bộ VieNeu SDK 3.3.0 và môi trường Python .venv đã được kỹ thuật viên cài đúng phiên bản.
  • Ba thông tin từ trường: URL API bắt đầu bằng https:// và kết thúc bằng /api/v1; URL tải gói model đầy đủ (manifest) qua HTTPS; mã kiểm tra SHA-256 của manifest. Hai thông tin model phải được trường xác nhận. File adapter fine-tune riêng không đủ để chạy.
Chưa có SDK, môi trường Python hoặc gói model?Hãy gửi bộ phận kỹ thuật: “Tôi cần bộ VieNeu SDK 3.3.0 đã cài môi trường Python tương thích, thư mục Backend-LearnAble có tts-agent, URL API HTTPS, URL manifest model và SHA-256 để dùng Local TTS.” Không tự chọn bản SDK hoặc model mới nhất thay thế.

Bạn không cần cài .NET, PostgreSQL hoặc chạy BE trên máy. Chương trình Local TTS sẽ kết nối tới BE của trường qua Internet.

2

Cài trên máy lần đầu

Làm lần lượt từng bước. Sau mỗi lệnh, xem kết quả đúng rồi mới sang bước tiếp theo.

  1. Mở PowerShell

    Nhấn phím Windows, gõ PowerShell và mở ứng dụng. Để nguyên cửa sổ này cho đến khi tạo audio xong. Không cần chọn “Run as administrator”.

    Ở mỗi khung lệnh bên dưới, bấm Sao chép, dán vào PowerShell bằng Ctrl+V, rồi nhấn Enter.

  2. Kiểm tra card NVIDIA

    Chạy lệnh sau. Nếu thấy tên card và thông tin driver, chuyển sang bước kế tiếp. Nếu báo không nhận lệnh hoặc không thấy GPU, nhờ kỹ thuật viên kiểm tra driver.

    Kiểm tra GPU
    nvidia-smi

    Kết quả đúngPowerShell hiện tên GPU NVIDIA và phiên bản driver. Bước này chưa xác nhận Python dùng được CUDA.

  3. Kiểm tra hai thư mục trường đã chuẩn bị

    Các đường dẫn dưới đây là ví dụ chuẩn của hướng dẫn. Nếu trường đặt ở chỗ khác, hãy xin đúng đường dẫn rồi sửa hai dòng đầu trước khi chạy.

    Đặt đường dẫn và kiểm tra file
    $ttsBackendRoot = 'C:\LearnAble\Backend-LearnAble'
$ttsSdkRoot = 'C:\LearnAble\VieNue-LoRA'
$ttsPython = Join-Path $ttsSdkRoot '.venv\Scripts\python.exe'
Test-Path (Join-Path $ttsBackendRoot 'tts-agent')
Test-Path $ttsPython

    Kết quả đúngHai dòng cuối đều hiện True. Nếu có False, máy chưa có đủ các thành phần; gửi ảnh kết quả cho bộ phận kỹ thuật và dừng tại đây.

  4. Cài agent và kiểm tra CUDA

    Chạy lệnh này trong cùng cửa sổ PowerShell. Lệnh cài phần kết nối LearnAble vào môi trường Python đã chuẩn bị; nó không tự cài VieNeu, PyTorch hoặc model.

    Cài agent và chạy kiểm tra
    Set-Location $ttsBackendRoot
& $ttsPython -m pip install -e ./tts-agent
$env:LEARNABLE_VIENEU_PATH = $ttsSdkRoot
& $ttsPython -m learnable_tts_agent.cli doctor

    Kết quả đúngLệnh doctor hiện tên GPU, dung lượng VRAM, phiên bản PyTorch và CUDA. Nó chưa kiểm tra khả năng tạo tiếng thật.

    Nếu báo No module named pip, bộ môi trường có thể dùng uv; nhờ kỹ thuật viên cài agent bằng uv pip install --python $ttsPython -e ./tts-agent. Nếu báo CUDA unavailable, nhờ kiểm tra driver và PyTorch trong đúng môi trường này.

  5. Tải gói giọng đọc do trường cấp

    Thực hiện từng ô lệnh riêng. Sau ô thứ nhất, dán URL manifest HTTPS và nhấn Enter. Sau ô thứ hai, dán mã SHA-256 và nhấn Enter. Nếu trường chưa cấp hai thông tin này, bạn chưa thể tải model.

    Nhập URL manifest
    $ttsManifestUrl = Read-Host 'Dan URL manifest HTTPS do truong cap'
    Nhập mã SHA-256
    $ttsManifestSha = Read-Host 'Dan SHA-256 manifest do truong xac nhan'
    Bắt đầu tải model
    & $ttsPython -m learnable_tts_agent.cli download-model --manifest-url $ttsManifestUrl --manifest-sha256 $ttsManifestSha

    Sau khi tải xong, PowerShell in ra đường dẫn thư mục model. Sao chép đường dẫn đó, rồi dùng ô lệnh cuối:

    Nhập đường dẫn model
    $ttsModelDir = Read-Host 'Dan duong dan thu muc model vua tai'
    Kiểm tra model đã tải
    Test-Path (Join-Path $ttsModelDir 'manifest.json')

    Kết quả đúngLệnh tải hoàn tất và ô cuối hiện True. Nếu thấy False, kiểm tra đường dẫn vừa dán. Không dùng một file adapter đơn lẻ thay cho gói đầy đủ.

Trường đưa checkpoint Kaggle thay vì URL tải model?Cách đó cần sẵn base model và codec cache trên máy. Nhờ kỹ thuật viên làm theo mục “Máy đã có checkpoint Kaggle và cache” trong tài liệu BE; các bước ở đây dành cho gói model có manifest để tránh thiếu file.
3

Kết nối và chạy

Tiếp tục trong cửa sổ PowerShell của phần cài đặt, sau khi model đã tải xong.

  1. Nhập địa chỉ API của trường

    Sao chép ô lệnh, dán vào PowerShell rồi nhấn Enter. Khi được hỏi, dán địa chỉ HTTPS mà trường cung cấp. Địa chỉ phải kết thúc bằng /api/v1; không dùng http://localhost:5080.

    Nhập URL API
    $env:LEARNABLE_API_URL = (Read-Host 'Dan URL API HTTPS ket thuc bang /api/v1').TrimEnd('/')

  2. Ghép máy với tài khoản Lecturer

    Nhập tên đăng nhập bằng ô đầu tiên. Sau đó chạy ô thứ hai. PowerShell sẽ hỏi mật khẩu: cứ gõ mật khẩu của bạn rồi nhấn Enter. Khi gõ mật khẩu, màn hình không hiện ký tự; đây là bình thường.

    Nhập tên đăng nhập
    $ttsIdentifier = Read-Host 'Nhap ten dang nhap Lecturer'
    Ghép máy
    & $ttsPython -m learnable_tts_agent.cli pair --identifier $ttsIdentifier --device-name "$env:COMPUTERNAME-TTS"

    Kết quả đúngPowerShell hiện Paired until ... với thời hạn ghép máy. Không gửi mật khẩu hoặc token cho người khác.

  3. Chạy chương trình tạo giọng đọc

    Chạy lệnh sau. Cửa sổ PowerShell sẽ tiếp tục mở để nhận công việc từ LearnAble. Cắm nguồn laptop và tránh để máy ngủ trong lúc tạo audio. Không cần mở cổng hay public IP.

    Chạy Local TTS
    & $ttsPython -m learnable_tts_agent.cli run --model-dir $ttsModelDir

    Kết quả đúngLệnh tiếp tục chạy và không trở về dòng nhập lệnh ngay. Model có thể cần thời gian nạp lần đầu. Hãy sang phần tiếp theo để thử audio thật.

Đừng đóng cửa sổ PowerShell khi đang tạo audio.Nhấn Ctrl+C để dừng sau khi các job hoàn tất. Cờ --smoke chỉ tạo audio im lặng để thử giao thức, không dùng cho tài liệu thật.
4

Thử tạo audio trên web

Bước này xác nhận máy thực sự tạo được giọng đọc, thay vì chỉ kiểm tra đã ghép tài khoản.

  1. Upload một PDF ngắn để thử

    Trong LearnAble, vào Learning Materials → Upload new material. Chọn PDF có chữ, điền Course và Topic, rồi bấm Upload material. Chức năng tạo audio theo trang hiện dành cho PDF; trang ảnh không có chữ cần nhập lời đọc thủ công.

  2. Kiểm tra lời đọc

    Sau khi upload, LearnAble mở Material Audio Studio. Chọn một trang, đọc lại phần văn bản trích xuất và sửa lời đọc nếu cần. Lưu lời đọc trước khi tạo audio.

  3. Tạo audio một trang

    Bấm Generate audio. Đây là yêu cầu gửi tới BE; agent đang chạy trên máy sẽ tự nhận. Đợi trạng thái hoàn tất. Sau khi trang thử chạy được, có thể dùng Generate all audio cho các trang còn lại.

  4. Nghe thử rồi phê duyệt

    Bấm Preview để nghe. Nếu rõ tiếng và đọc đúng, bấm Approve. Nếu chưa đúng, sửa lời đọc và dùng Regenerate audio.

    Hoàn tất kiểm traBạn đã nghe được audio thật từ PDF thử. Trạng thái “thiết bị đã ghép” trên trang upload chỉ cho biết token còn hiệu lực, không thay thế bước nghe thử này.

5

Những lần sử dụng sau

Mỗi khi muốn tạo audio, mở lại PowerShell và chạy agent trước khi bấm Generate audio trên web.

  1. Mở PowerShell và đặt lại đường dẫn

    Các biến trong PowerShell mất khi đóng cửa sổ. Nếu thư mục của trường khác ví dụ, sửa hai dòng đầu.

    Chuẩn bị cửa sổ mới
    $ttsSdkRoot = 'C:\LearnAble\VieNue-LoRA'
$ttsPython = Join-Path $ttsSdkRoot '.venv\Scripts\python.exe'
$env:LEARNABLE_VIENEU_PATH = $ttsSdkRoot

  2. Nhập lại URL API và thư mục model

    Nhập đúng URL API đã dùng lúc ghép máy và đường dẫn model được in khi tải lần đầu.

    Nhập URL API
    $env:LEARNABLE_API_URL = (Read-Host 'Dan lai URL API HTTPS ket thuc bang /api/v1').TrimEnd('/')
    Nhập đường dẫn model
    $ttsModelDir = Read-Host 'Dan duong dan thu muc model da tai'

  3. Chạy agent rồi tạo audio trên web

    Dùng lệnh sau và giữ cửa sổ mở. Nếu agent báo cần ghép lại, quay lên bước “Ghép máy với tài khoản Lecturer”; token hiện hết hạn sau 8 giờ.

    Chạy Local TTS
    & $ttsPython -m learnable_tts_agent.cli run --model-dir $ttsModelDir

  4. Nếu máy đã cài bằng adapter LoRA

    Máy thử nghiệm đã cài theo cách này. Mở PowerShell mới, sao chép toàn bộ lệnh dưới đây; không cần cài lại. Nếu đường dẫn cài đặt khác, sửa các đường dẫn trước khi chạy.

    Chạy lại trên máy dùng adapter
    $ttsSdkRoot = 'C:\Capstone2026\VieNue-LoRA'
$ttsPython = Join-Path $ttsSdkRoot '.venv\Scripts\python.exe'
$ttsAdapter = Join-Path $ttsSdkRoot 'finetune\output\kaggle\vieneu-lora\ngoc_huyen-full-20261108-1234-s42\best_adapter'
$env:LEARNABLE_VIENEU_PATH = $ttsSdkRoot
$env:LEARNABLE_API_URL = 'https://backend-learnable.onrender.com/api/v1'
Set-Location 'C:\Capstone2026\Backend-LearnAble-TTS'
& $ttsPython -m learnable_tts_agent.cli run --adapter-dir $ttsAdapter --adapter-sha256 'ff93e9d4d599873a2db3636220a31fe7771d884f5fe0583e7314cca9280bd745' --preset-voice ngoc_huyen

    Nếu báo hết hạn ghép máy, dùng lệnh dưới đây trong cùng cửa sổ rồi chạy lại dòng run. Khi nhập mật khẩu, PowerShell không hiện ký tự.

    Ghép lại khi hết hạn
    & $ttsPython -m learnable_tts_agent.cli pair --identifier 'LEC0001' --device-name "$env:COMPUTERNAME-TTS"

    Giữ cửa sổ agent mở trong lúc tạo audio; nhấn Ctrl+C để dừng. Agent sẽ lấy job cũ nhất đang chờ của tài khoản Lecturer. Nếu tài liệu cũ còn job, agent xử lý chúng trước tài liệu mới. Hãy hủy job cũ trên hệ thống trước khi chạy lại nếu muốn chuyển tài liệu.

Nếu gặp lỗi

Tìm câu giống tình huống của bạn. Nếu không xử lý được, gửi thông báo lỗi cho bộ phận kỹ thuật.

Không có thư mục hoặc một dòng kiểm tra hiện False

Chưa đủ file để cài. Gửi bộ phận kỹ thuật đường dẫn đã dùng và ảnh hai dòng Test-Path; cần đúng thư mục tts-agent và file .venv\Scripts\python.exe. Không tự tải một model khác về thay thế.

nvidia-smi không chạy hoặc doctor báo CUDA unavailable

Máy cần GPU NVIDIA được PyTorch trong môi trường SDK nhận diện. Nhờ kỹ thuật viên kiểm tra driver và bản PyTorch CUDA đã bàn giao. Máy chỉ có CPU hoặc GPU tích hợp chưa chạy được agent này.

Tải model lỗi hoặc mã SHA-256 không khớp

Kiểm tra URL manifest HTTPS và mã SHA-256 đã nhận từ trường, sau đó thử lại. Nếu vẫn lỗi, xin lại gói model và mã kiểm tra qua kênh tin cậy. Không bỏ qua kiểm tra checksum.

Ghép máy thất bại

Kiểm tra URL API có https:// và kết thúc bằng /api/v1, tài khoản Lecturer còn hoạt động và đã đổi mật khẩu bắt buộc. Nếu lỗi chứng chỉ HTTPS, nhờ kỹ thuật viên xử lý; không tắt kiểm tra chứng chỉ. Nếu báo quá nhiều thiết bị, nhờ thu hồi thiết bị cũ.

Agent yêu cầu ghép lại hoặc web vẫn báo chưa kết nối

Token hiện hết hạn sau 8 giờ. Dừng agent, chạy lại bước ghép máy với cùng URL API, rồi chạy agent lại. Nếu web vẫn báo chưa kết nối, kiểm tra máy có Internet và cửa sổ PowerShell còn chạy.

Audio chờ lâu, upload thất bại hoặc nghe im lặng

Kiểm tra agent vẫn chạy và không dùng chế độ --smoke (chỉ tạo âm thanh im lặng). Ghi lại thời điểm lỗi và tên tài liệu để bộ phận kỹ thuật kiểm tra job, model và kết nối lưu audio. Không gửi mật khẩu, token hoặc URL upload có chữ ký.
