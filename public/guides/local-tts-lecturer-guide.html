Cài Local TTS từng bước một

Ứng dụng Windows dùng GPU NVIDIA trên máy giảng viên để tạo audio. Bạn chỉ cần cài ứng dụng, chọn bộ model do trường cấp và kết nối máy với LearnAble.

1

Chuẩn bị

Đảm bảo máy và thông tin bàn giao đã sẵn sàng.

Máy cần Windows 10/11 64-bit, GPU NVIDIA hoạt động, Internet và khoảng 15 GB dung lượng trống để cài ứng dụng, giải nén model và lưu file tạm. Bạn có thể xem tên GPU trong Task Manager → Performance → GPU.

Tải một gói từ Google DriveMở LearnAble-TTS-Handoff.zip, chọn biểu tượng tải xuống của Google Drive rồi giải nén file vừa tải. Trong thư mục LearnAble-TTS-Handoff có LearnAble-TTS-Setup.exe, model-ngoc-huyen-kaggle-20261108.zip và file .zip.sha256 cùng tên. Nhóm triển khai cần kiểm tra ZIP model khớp mã SHA-256 trước khi phát. Bạn không cần tự cài Python, CUDA Toolkit hoặc chạy Backend.

Gói này được cài từ thư mục trên máy. URL artifacts.invalid bên trong manifest không phải link tải; bạn không cần tìm URL manifest HTTPS.

Tải README để xem khi không mở trang này.

2

Cài ứng dụng và model

Làm một lần trên máy dùng để tạo audio.

  1. Chạy bộ cài

    Mở LearnAble-TTS-Setup.exe, làm theo màn hình cài đặt, rồi mở LearnAble TTS Agent từ Start Menu. Ứng dụng chạy nền và không mở cửa sổ chính. Ở góc phải taskbar, bấm dấu ^ để xem các biểu tượng ẩn; tìm biểu tượng hình chiếc loa có tên LearnAble TTS Agent, rồi nhấp chuột phải để mở menu. Nếu mở lại từ Start Menu và thấy “already running in the system tray”, hãy quay về biểu tượng đang chạy thay vì mở thêm lần nữa.

  2. Nhập địa chỉ LearnAble

    Nhấp chuột phải vào biểu tượng, chọn Settings. Ở API URL (include /api/v1), nhập https://api.learnable.site/api/v1. Ở Web dashboard URL, nhập địa chỉ HTTPS trang Lecturer cùng môi trường nếu trường đã cung cấp; có thể để trống khi thử trên localhost. Đặt Device label để dễ nhận ra máy; để trống Runtime executable (optional).

  3. Giải nén và chọn đúng thư mục model

    Giải nén model-ngoc-huyen-kaggle-20261108.zip vào nơi cố định, ví dụ C:\LearnAble-TTS-Model. Mở thư mục model sau khi giải nén; trong đó phải thấy trực tiếp manifest.json và manifest.sha256. Chọn chính thư mục model tại Verified model folder, rồi nhấn OK. Không chọn file ZIP hoặc thư mục bao ngoài và không di chuyển model sau khi chọn.

  4. Kiểm tra GPU

    Chọn Check GPU. Hộp thoại cần thấy GPU NVIDIA, VRAM, PyTorch và CUDA. Kiểm tra này chưa thay thế bước tạo audio thử.

3

Kết nối thiết bị

Dùng thông tin một lần từ trang Lecturer.

  1. Mở Pair Device

    Trên ứng dụng Windows, chọn Pair Device và để cửa sổ này mở.

  2. Đăng ký máy trên web

    Đăng nhập trang Lecturer cùng môi trường với API trong Settings. Chọn Pair TTS Device ở sidebar. Nhập tên máy rồi chọn Đăng ký máy.

  3. Dán thông tin vào ứng dụng

    Chép Agent ID và Expires at (ISO 8601). Chọn Sao chép token một lần rồi dán vào Device token. Nhấn OK và chờ báo kết nối thành công. Thông tin trên web tự ẩn sau hai phút.

Giữ kín tokenKhông gửi token hay ảnh chụp token cho người khác. Token hết hạn sau khoảng tám giờ; khi hết hạn, đăng ký máy mới và Pair Device lại. Khi đổi tài khoản, chọn Unpair Device trước.

Nếu trang Lecturer chưa có mục đăng ký, nhóm triển khai có thể cấp trang BE /local-tts/ của cùng môi trường.

4

Tạo audio thử

Thử một trang ngắn trước khi làm cả tài liệu.

  1. Giữ ứng dụng đang chạy

    Cắm nguồn laptop, giữ Internet và tránh chế độ Sleep.

  2. Chọn trang PDF có chữ

    Mở Material Audio Studio, kiểm tra phần text sẽ đọc, chọn một trang ngắn và yêu cầu tạo audio.

  3. Nghe và duyệt

    Chờ web báo audio đã sẵn sàng, chọn Preview để nghe. Chỉ Approve khi giọng đọc đúng. Sau đó mới tạo audio cho cả tài liệu.

Ứng dụng có thể hiện IDLE, GENERATING hoặc UPLOADINGIDLE là đang chờ việc; GENERATING là đang tổng hợp; UPLOADING là đang gửi audio về hệ thống.
5

Tạo audio cho câu hỏi

Dùng cùng ứng dụng và thiết bị đã ghép để tạo giọng đọc câu hỏi.

  1. Lưu câu hỏi

    Trên trang Lecturer, mở phần quản lý câu hỏi rồi tạo hoặc chỉnh sửa câu hỏi. FE sẽ gửi yêu cầu tạo audio sau khi lưu thành công khi Backend hỗ trợ Local TTS.

  2. Kiểm tra trạng thái audio

    Mở câu hỏi đã lưu và xem phần trạng thái audio. Nếu cần tạo các phần còn thiếu, chọn Create with Local TTS. Câu trắc nghiệm có audio riêng cho câu hỏi và từng đáp án.

  3. Chờ và nghe thử

    Giữ ứng dụng Windows đang chạy. Khi các phần audio đã sẵn sàng, nghe thử trước khi dùng trong bài thi hoặc bài luyện tập.

Kiểm tra môi trườngỨng dụng đang dùng API EC2 nên trang Lecturer cũng phải dùng cùng BE EC2. Nếu web dùng BE khác, thiết bị đã ghép sẽ không nhận được job.
6

Dùng lại và xử lý lỗi

Không phải cài lại mỗi lần tạo audio.

Những lần sau, mở ứng dụng từ Start Menu hoặc để ứng dụng tự chạy cùng Windows. Nếu thấy PAIRING_REQUIRED, đăng ký lại thiết bị trên web. Pause / Resume chỉ tạm dừng nhận job mới; job đang chạy vẫn tiếp tục.

Báo “already running” nhưng không thấy biểu tượng

Ứng dụng đã chạy nền, không mở cửa sổ chính. Nhấn Win + B hoặc bấm dấu ^ cạnh đồng hồ ở góc phải taskbar; tìm biểu tượng chiếc loa có tên LearnAble TTS Agent và nhấp chuột phải. Nếu vẫn không thấy, vào Windows Settings → Personalization → Taskbar → Other system tray icons và bật LearnAble TTS Agent nếu có. Nếu không có cả trong danh sách này, mở Task Manager → Details, kết thúc LearnAble-TTS-Agent.exe rồi chạy lại từ Start Menu. Nếu vẫn lặp lại, gửi ảnh toàn bộ góc phải taskbar cho nhóm hỗ trợ.

Check GPU không thấy NVIDIA

Kiểm tra GPU trong Task Manager và driver NVIDIA. Khởi động lại Windows sau khi cập nhật driver. Gửi tên GPU và lỗi cho nhóm kỹ thuật.

MODEL_SETUP_REQUIRED hoặc model lỗi

Kiểm tra đã chọn đúng thư mục model chứa trực tiếp hai file manifest. Nhờ nhóm triển khai đối chiếu mã SHA-256 của ZIP với file .zip.sha256 hoặc gửi lại gói nếu cần.

Ứng dụng báo IDLE nhưng web đang chờ audio

Kiểm tra web và ứng dụng dùng cùng API/môi trường, cùng tài khoản Lecturer và model tương thích. Gửi thời điểm và mã lỗi cho nhóm kỹ thuật.

Audio chờ lâu hoặc thất bại

Chọn View Logs trong menu ứng dụng. Gửi mã lỗi, thời điểm, tên GPU; không gửi token, mật khẩu hoặc URL upload có chữ ký.

Trước khi gỡ cài đặt hoặc đổi tài khoản, chọn Unpair Device. Nếu máy mất mạng, thu hồi thiết bị trên web khi có mạng trở lại.
