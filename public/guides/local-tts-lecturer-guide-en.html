Set up Local TTS step by step

The Windows app uses your NVIDIA GPU to generate audio. Install the app, select the model supplied by your school, and pair your computer with LearnAble.

1

Before you begin

Check your computer and the package from your school.

You need Windows 10/11 64-bit, a working NVIDIA GPU, internet access, and about 15 GB of free space. Find your GPU name in Task Manager → Performance → GPU.

Download one package from Google DriveOpen LearnAble-TTS-Handoff.zip, download it, and extract it. Inside the LearnAble-TTS-Handoff folder, find LearnAble-TTS-Setup.exe, model-ngoc-huyen-kaggle-20261108.zip, and its matching .zip.sha256 file. The deployment team should verify the checksum before distributing the model. You do not need Python, the CUDA Toolkit, or a local Backend.

This package installs from a local folder. artifacts.invalid in the manifest is not a download URL.

Download the English README for offline use.

2

Install the app and model

Do this once on the computer that will create audio.

  1. Run the installer

    Open LearnAble-TTS-Setup.exe, follow the installer, and open LearnAble TTS Agent from the Start Menu. The app runs in the background without a main window. Click ^ near the Windows clock, find its speaker icon, and right-click it. If starting it again says “already running in the system tray,” use the existing icon.

  2. Enter the LearnAble addresses

    Choose Settings. In API URL (include /api/v1), enter https://api.learnable.site/api/v1. For Web dashboard URL, enter the HTTPS Lecturer website for the same environment if supplied; leave it blank for localhost testing. Set a recognizable Device label and leave Runtime executable (optional) blank.

  3. Select the correct model folder

    Extract model-ngoc-huyen-kaggle-20261108.zip to a permanent location such as C:\LearnAble-TTS-Model. Open the inner model folder. It must directly contain manifest.json and manifest.sha256. Select that folder in Verified model folder, then click OK. Do not select the ZIP or outer folder, and do not move the model afterward.

  4. Check the GPU

    Select Check GPU. You should see an NVIDIA GPU, VRAM, PyTorch, and CUDA. You still need a short audio test to confirm that generation works.

3

Pair the device

Use one-time details from the Lecturer website.

  1. Open Pair Device

    In the Windows agent menu, choose Pair Device and keep that window open.

  2. Register on the website

    Sign in to the Lecturer website for the same API environment. Select Pair TTS Device in the sidebar. Enter a device name and choose Đăng ký máy (Register device).

  3. Paste the details into the app

    Copy Agent ID and Expires at (ISO 8601). Choose Sao chép token một lần (Copy token once), paste it into Device token, then click OK. The web page hides the token after two minutes.

Keep the token privateDo not share the token or a screenshot of it. The device credential expires after about eight hours. Pair again when it expires; choose Unpair Device before switching accounts.

If the Lecturer website has no registration option, the deployment team may provide the Backend /local-tts/ page for the same environment.

4

Generate sample audio

Try one short page before a whole document.

  1. Keep the app running

    Plug in your laptop, keep internet connected, and prevent sleep.

  2. Choose a page with text

    Open Material Audio Studio, review the text to be spoken, select a short page, and request audio.

  3. Listen and approve

    Wait until audio is ready. Select Preview, listen, and select Approve only when it sounds right. Then generate audio for the whole document.

The app may show IDLE, GENERATING, or UPLOADINGIDLE means waiting for work; GENERATING means producing speech; UPLOADING means sending audio to LearnAble.
5

Generate question audio

Use the same paired app for questions.

  1. Save a question

    In the Lecturer workspace, create or edit a question and save it. The FE requests Local TTS audio after a successful save when the Backend supports it.

  2. Check audio status

    Open the saved question and inspect its audio status. To generate missing parts, choose Create with Local TTS. Multiple-choice questions have separate audio for the question and each answer.

  3. Wait and listen

    Keep the Windows app running. Listen before using the question in an exam or practice activity.

Use the same environmentIf the agent uses the EC2 API, the Lecturer website must use that same EC2 Backend; otherwise the agent will not receive its jobs.
6

Daily use and troubleshooting

You do not need to reinstall the app each time.

On later days, open the app from the Start Menu or let it start with Windows. If it shows PAIRING_REQUIRED, pair again. Pause / Resume stops accepting new jobs; a job already running continues.

“Already running,” but I cannot see the icon

Press Win + B or click ^ beside the clock. Look for LearnAble TTS Agent. If missing, check Windows Settings → Personalization → Taskbar → Other system tray icons. If absent there too, end LearnAble-TTS-Agent.exe in Task Manager → Details, then start it again.

Check GPU does not show NVIDIA

Check Task Manager and update the NVIDIA driver. Restart Windows afterward and send the GPU name to support.

MODEL_SETUP_REQUIRED or invalid model

Select the inner model folder containing both manifest files. Ask the deployment team to verify the ZIP checksum.

The agent is IDLE while audio is waiting

Confirm that the website and agent use the same API environment, Lecturer account, and compatible model version.

Audio waits too long or fails

Open View Logs. Send support the error code, time, and GPU name, but never a token, password, or signed upload URL.

OFFLINE — NETWORK_UNAVAILABLE

Check the API URL and internet. A registered device does not prove that the agent receives jobs. If the issue continues, ask the Backend team to check heartbeat and job claim. An empty Web dashboard URL does not cause offline status.

Before uninstalling or changing accounts, choose Unpair Device. If the app was offline, revoke the old registration on the website after connectivity returns.
